選擇權四大基本部位：到期 Payoff 與淨損益

橫軸為到期時標的價格 ST；縱軸以「每 1 單位標的」計算。 實線是淨損益（含權利金），虛線是到期 Payoff（未含權利金）。

Long Call（買進買權 / Buy Call）

Long Put（買進賣權 / Buy Put）

Short Call（賣出買權 / Sell Call）

Short Put（賣出賣權 / Sell Put）

公式：
Long Call payoff = max(S_T − K, 0)；Long Put payoff = max(K − S_T, 0)。
Short 的 payoff = 對應 Long payoff 乘以 −1。
Long 淨損益 = payoff − premium；Short 淨損益 = payoff + premium。

重要：權利金使淨損益線相對 payoff 線做的是垂直位移，不是水平位移； 但因為損益平衡點必須滿足 P&L = 0，所以 break-even 會在橫軸上移動。
